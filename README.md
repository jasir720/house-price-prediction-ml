 House Price Prediction Using Machine Learning

 Project Overview

This project focuses on predicting median house values using Machine Learning techniques. A Linear Regression model is developed using Python and Scikit-learn to understand how different housing features influence house prices.

The project includes data preprocessing, handling missing values, encoding categorical variables, feature scaling, model training, and performance evaluation.

 Objective

To build a Machine Learning model that predicts median house values based on available housing features.

 Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

 Project Workflow

1. Import required Python libraries.
2. Load and inspect the housing dataset.
3. Check missing values and duplicate records.
4. Separate independent and dependent variables.
5. Split the dataset into training and testing sets.
6. Handle missing values using SimpleImputer.
7. Scale numerical features using StandardScaler.
8. Encode categorical features using OneHotEncoder.
9. Train the Linear Regression model.
10. Predict median house values.
11. Evaluate model performance.
12. Identify important features using regression coefficients.

 Machine Learning Algorithm

Linear Regression

Target Variable: "median_house_value"

The model uses housing-related features to predict median house values.

 Model Evaluation Metrics

The model performance is evaluated using:

- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
